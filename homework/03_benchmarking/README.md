## 3. Анализ и сравнение

### 3.1 Обязательные функции для нашего продукта (исходя из анализа конкурентов)

| Функция | Почему обязательна | У кого есть |
|---------|-------------------|-------------|
| **REST API** | Стандарт индустрии, все конкуренты предоставляют API | Все |
| **Асинхронная обработка видео** | Deepfake-детекция требует анализа временных последовательностей, синхронный запрос не подходит для длинных видео | Не у всех (у Reality Defender пока только аудио/изображения) |
| **Confidence score** | Пользователи ожидают не только бинарный ответ, но и меру уверенности | Все |
| **Документация API (Swagger)** | Ожидание разработчиков | Facia, Reality Defender |
| **Мониторинг и аналитика** | Enterprise клиенты требуют отчётности | Facia (Analytics Dashboard), Reality Defender |

### 3.2 Функции для дифференциации (чем мы будем отличаться)

| Функция | Конкурентное преимущество | Почему это важно |
|---------|--------------------------|-----------------|
| **Анализ временной последовательности (LSTM/Transformer)** | Большинство конкурентов фокусируются на кадровом анализе; временной анализ даёт преимущество в точности | Ключевое преимущество перед Facia и Reality Defender |
| **Поддержка видео как основного формата** | Reality Defender пока не поддерживает видео, Facia — да, но дорого | Заполняем нишу |
| **On-premise развертывание** | Для государственных и финансовых организаций критично | Некоторые конкуренты предлагают, но не все |
| **Прозрачность модели (explainable AI)** | Растёт требование к объяснимости решений, особенно в регулируемых отраслях | Согласно TRIED Benchmark от WITNESS [citation:9] |
| **Адаптивность к новым типам deepfake** | Быстрое дообучение на новых данных | Ключевое преимущество перед устаревающими решениями (Microsoft) |

### 3.3 Недостатки конкурентов, которые мы можем устранить

| Недостаток конкурента | Как устраняем |
|----------------------|---------------|
| **Microsoft Video Authenticator:** не справляется с новыми генерациями deepfake | Регулярное дообучение на актуальных датасетах, CI/CD для модели |
| **Facia AI:** высокая стоимость ($0.40/check) | Конкурентная цена ($0.10-0.20/check) |
| **Intel FakeCatcher:** закрытое решение, нет API | Открытое API, freemium модель |
| **Reality Defender:** пока нет поддержки видео | Видео как основной фокус |
| **Общий недостаток:** высокий порог входа для малого бизнеса | Бесплатный тариф на разумное количество проверок (как у Reality Defender) |
| **Общий недостаток:** проблемы с генерализацией на разных доменах | Прозрачное тестирование на Celeb-DF, документирование результатов |

### 3.4 Стратегии монетизации

| Стратегия | Эффективность | Применимость к нашему продукту |
|-----------|---------------|-------------------------------|
| **Freemium** (бесплатные проверки + платные) | Высокая — Reality Defender показывает успешность | ✅ Да — 50-100 бесплатных проверок/мес |
| **Pay as you go** ($0.10-0.40/check) | Высокая — Facia показывает спрос | ✅ Да — целевая цена $0.10-0.20 |
| **Enterprise subscription** | Высокая — основной источник дохода B2B | ✅ Да — для крупных клиентов |
| **On-premise лицензия** | Средняя — для регулируемых отраслей | ✅ Да — для госсектора и финансов |
| **Бесплатно с ограничениями** | Низкая (нет бизнес-модели) | ❌ Нет — нужна монетизация |

**Наиболее эффективная модель для нашего продукта:** Freemium + Pay as you go + Enterprise (гибридная модель)

### 3.5 Улучшение пользовательского опыта

1. **Рынок deepfake-детекции растёт экспоненциально** — CAGR 25-37% [citation:6][citation:10]
2. **Основные игроки:** Reality Defender, Facia, Intel, Sensity, Microsoft
