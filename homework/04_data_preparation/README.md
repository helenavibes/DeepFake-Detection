# Домашнее задание №4. Подготовка данных (Data Preparation)

## Проект: DeepFake-детекция для медиа-безопасности

---

### 1.1 Источник и состав данных

#### Используемые датасеты

| Датасет | Real | Fake | Методы подделки | Лицензия |
|---------|------|------|----------------|----------|
| FaceForensics++ | 1,000 | 4,000 | DeepFakes, FaceSwap, Face2Face, NeuralTextures | CC BY-NC 4.0 |
| Celeb-DF | 590 | 5,639 | DeepFake (улучшенный) | Research only |

**Релевантность атрибутов:**
- **Кадры видео** — основной признак, высокая релевантность
- **Аудиодорожка** — не используем в MVP (добавим позже)
- **Метаданные** (имя файла, дата) — не релевантны, исключаем

**Качество данных:**
- 98% видео открываются корректно
- Для FF++ разметка по папкам, для Celeb-DF — по имени файла

**Ограничения:**
- Биометрия (лица) — только из датасетов с согласием субъектов
- Реальные пользовательские данные не собираем

### 1.2 Базовый EDA с выводами для моделирования

#### Проверка целостности
- FF++: ~98% видео корректны
- Celeb-DF: ~99% видео корректны

#### Распределение классов
- FF++: 20% real / 80% fake → **сильный дисбаланс**
- Celeb-DF: 9.5% real / 90.5% fake → **очень сильный дисбаланс**

**Вывод:** нужен Weighted Sampler (вес real-класса = 4.0)

#### Распределение длительности
- FF++: средняя 12 сек (3-30 сек)
- Celeb-DF: средняя 18 сек (5-45 сек)

**Вывод:** берём клипы по 20 кадров, видео короче 10 кадров удаляем

#### Разрешение кадров
- FF++: в основном 854×480 (45%)
- Celeb-DF: в основном 1920×1080 (85%)

**Вывод:** ресайз к 224×224 (стандарт для EfficientNet)

### 1.3 Оценка качества разметки и предложения по повышению

| Проблема | Решение |
|----------|---------|
| Нет разметки по типу deepfake | Для FF++ можно добавить (данные есть в структуре папок) |
| Дисбаланс классов | Weighted sampler + аугментация меньшего класса |
| Нет публичной разметки для Celeb-DF | Используем разметку по имени файла |

**Проверка утечки данных:** в FF++ нет пересечений (гарантировано авторами)

### 1.4 Алгоритм формирования выборки и стратегия валидации

#### Разделение данных

| Выборка | FF++ real | FF++ fake | Всего |
|---------|-----------|-----------|-------|
| Train (70%) | 700 | 2,800 | 3,500 |
| Validation (15%) | 150 | 600 | 750 |
| Test (15%) | 150 | 600 | 750 |

**Принципы:**
- Стратификация (сохранение пропорции классов)
- Все кадры одного видео — в одной выборке (нет утечки)
- Random seed = 42

#### Аугментация (пространственная)

| Тип | Вероятность |
|-----|-------------|
| Horizontal Flip | 0.5 |
| Rotate (-10°…+10°) | 0.3 |
| Brightness/Contrast | 0.5 |
| Gauss Noise | 0.3 |

#### Аугментация (временная)

| Тип | Вероятность |
|-----|-------------|
| Обратный порядок кадров | 0.3 |
| Пропуск кадров | 0.3 |

#### Нормализация
ImageNet: `mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`

#### Балансировка классов
Weighted Random Sampler: вес real = 4.0, fake = 1.0
